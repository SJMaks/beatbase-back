# BeatBase  Backend

Бэкенд-сервис инструмента, который автоматизирует ранний этап продаж битов для действующего музыкального продюсера.

## Контекст

BeatBase делается под реального заказчика: независимого битмейкера с опытом 7+ лет и большим каталогом готовых битов. Как и большинство продюсеров, он тратит больше времени на рутину вокруг продаж (поиск артистов в соцсетях, сбор контактов, ведение таблиц), чем на музыку, а ручной процесс даёт лишь единичные продажи.

Продукт закрывает первый и самый болезненный шаг цепочки: поиск артистов, которые потенциально могут купить бит, обогащение их публичных профилей и ведение структурированной базы лидов, где каждое значимое значение несёт информацию о своём происхождении.

Вне рамок первой версии: рассылки, персональные паки битов, учёт отправок.

## Функционал

- **Сначала ручной импорт.** Артиста можно добавить по Spotify ID или URL, запись создаётся даже если Spotify API недоступен, полезные данные никогда не блокируются внешней зависимостью.
- **Обогащение профиля** из публичных источников (Spotify обязательный минимум; YouTube, SoundCloud, TikTok и официальные сайты опционально, не блокируют пайплайн).
- **Происхождение на уровне поля.** Для каждого значимого значения сохраняется источник, время получения и признак ручной проверки.
- **Ручные правки защищены.** Поле, подтверждённое вручную, никогда не перезаписывается автоматическим обогащением.
- **Строгая дедупликация** по Spotify ID. Записи без Spotify ID не объединяются автоматически, точность важнее объёма.
- **Бэкап базы данных** входит в MVP, а не откладывается на потом.

## Планируемый стек

- **Язык:** Go
- **HTTP:** Gin
- **База данных:** PostgreSQL через `pgx/v5`
- **Миграции:** `golang-migrate`
- **Логирование:** Zap
- **Локальное окружение:** Docker Compose
- **Тестирование:** unit + integration tests

Подключается постепенно, только после работающего MVP-ядра: `sqlc`, `gRPC`, `Swagger`, `Redis`, `Kafka`

## Статус

Ранняя стадия разработки. Текущая веха: первый рабочий вертикальный срез (ручной импорт + обогащение + база лидов).
